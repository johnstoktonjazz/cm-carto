## Правила источников

**Overture.** Односторонность — в `access_restrictions` сегмента: запись `access_type = denied` с условием из одного `heading` (без `mode`, `during`, `using` и прочего; запрет для велосипедов с `heading` односторонности не задает). `heading` отсчитывается от направления линии сегмента: `forward` — по линии, `backward` — против. Запрет `backward` значит движение только по линии, запрет `forward` — только против, тогда линия при записи разворачивается, потому что в контракте `oneway` — «по направлению линии». Запись с `between` относится только к части сегмента (участок режется по ней, как по источникам). Запрет в обе стороны на одном участке — ошибка. Мост — флаг `is_bridge` в `road_flags` (с учетом `between`). Линии односторонних улиц собираются `line_merge(directed=True)`, чтобы склейка не меняла направление.

Один элемент OSM дает несколько записей, если у его участков различаются тоннель, мост или односторонность. Ключ `-t` у тоннеля прежний; новые окончания `-b` (мост) и `-o` (односторонний) ставятся только тому участку, у которого признак истинен, и только если признак у участков элемента различается. Один вариант или одинаковые признаки — ключ без изменений, поэтому существующие `object_id` не поменялись (на полигоне добавились только два).

**OSM напрямую.** `oneway` в `yes`, `1`, `true` — по линии; `-1`, `reverse` — против линии (геометрия разворачивается до обрезки охватом); любое другое значение (`no`, `reversible`) — двусторонняя. Без тега `oneway` односторонними считаются `junction=roundabout`, `highway=motorway`, `highway=motorway_link` (список в правилах; явный `oneway=no` его отменяет). `bridge` — любое значение, кроме `no`.

Значения у `roads` пишутся всегда (`true`/`false`): оба источника сообщают их по каждой улице. У `rail` столбцов нет (в схеме их у rail нет). Улицы из других источников (чертеж DXF) без атрибутов остаются null, граф трактует это как двустороннюю, не мост.
