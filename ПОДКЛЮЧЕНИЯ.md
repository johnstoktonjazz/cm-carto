# Подключения: внешние источники картографа

Каждое подключение — модуль `cm_carto/fetch/`, правила раскладки в `rules/fetch.yaml` и `rules/registries.yaml`, кеш сырых данных в `input/<проект>/cache/` (в git не попадает), часть геопакета `geo/parts/fetch-*.gpkg`. Статус всех объектов из внешних источников — `reference`; в каждой записи подпись источника (`source_label`), дата (`source_date`) и лицензия (`source_license`).

Класс доверия:

| Класс | Что значит |
|---|---|
| A | официальный реестр: сведения подает владелец; геометрия все равно `reference`, пока ее не подтвердил документ |
| B | открытая карта с правкой сообществом (OSM): полнота и свежесть разные по районам |
| C | сборный набор из частных и машинных источников (Overture Places, Microsoft ML Buildings): положение приблизительное, возможны устаревшие записи |
| D | только сверка и счет; в карты и геопакет не попадает |

Команда: `cm-carto fetch <project.yaml> <источник>`; выпуск Overture — `fetch.overture_release` в `project.yaml` или `--release`.

## Overture Maps: OSM-темы (улицы, ж/д, остановки, застройка, зелень, вода)

- **Что дает.** `transportation/segment` → `roads`, `rail`; `base/infrastructure` → `transit_stops`; `buildings/building` → `buildings_osm`; `base/land_use`, `base/land` → `green`; `base/water` → `water` (море — `sea`, из полигонов Overture); `base/land_use` (школы, детские сады, колледжи, вузы, больницы) → `poi_*`; производный слой `blocks` (суша охвата минус полосы улиц, ширины в `rules/fetch.yaml`).
- **Доступ.** Анонимный S3: `s3://overturemaps-us-west-2/release/<выпуск>/theme=<тема>/type=<тип>/` (регион us-west-2), Parquet; читается `pyarrow.dataset` с отбором по `bbox` без скачивания целых файлов. Каталог выпусков — docs.overturemaps.org.
- **Лицензия и атрибуция.** Данные OSM и Microsoft ML Buildings — ODbL 1.0. Подпись на карте: «© участники OpenStreetMap, ODbL 1.0; Overture Maps Foundation». Карта — производная работа (Produced Work): достаточно подписи. Геопакет с этими слоями — база данных: при передаче третьим лицам ее условия — ODbL (share-alike). Юридическую оценку передачи делает Роман.
- **Свежесть.** Выпуск Overture выходит раз в месяц; записи OSM внутри — снимок планеты на дату `sources.version` (для выпуска 2026-09-23.0 — 2026-09-09). Дата выпуска пишется в `source_date`, имя выпуска — в `source_label` и в `SOURCE.yaml` кеша.
- **Кеш.** `input/<проект>/cache/overture-<выпуск>/`: `<тема>-<тип>.parquet` (GeoParquet, столбцы из `rules/fetch.yaml`) и `SOURCE.yaml` (выпуск, дата выгрузки, охват, лицензии, число записей по поставщикам). Повторный запуск при наличии `SOURCE.yaml` сеть не трогает; кеш на другой охват — ошибка, кеш удаляется вручную. Размер для полигона — 11 МБ.
- **Как собраны объекты.** Сегмент Overture режется по исходным элементам OSM и по флагам тоннеля, дальше участки одного элемента собираются в одну запись: `roads:osm-w123`, подземный участок — `roads:osm-w123-t`. Ключ `object_id` — номер элемента OSM из `sources[].record_id` (`w123@4` → `osm-w123`), иначе GERS (`ovt-<id>`). Заброшенные и строящиеся участки не берутся.
- **Ограничения.** В выпуске нет остановок трамвая (в `base/infrastructure` только автобус, паром, ж/д), поэтому `mode = tram` не заполняется; станционные и подъездные пути в `rail` не отличаются (`siding` в Overture не выделен); `track` отнесен к `service`; этажность есть у 12 % зданий; здания Microsoft ML Buildings (около половины) без названий и без номера OSM. Закрытых источников нет — все получено.

## Overture Maps Places

- **Что дает.** `places/place` → `poi_education`, `poi_health`, `poi_culture`, `poi_hotels`, `poi_other` по `taxonomy.primary` (таблица в `rules/fetch.yaml`). Точка Places внутри площадного объекта `land_use` той же группы отбрасывается как дубль; уверенность ниже 0,5 и закрытые заведения не берутся.
- **Доступ.** `s3://overturemaps-us-west-2/release/<выпуск>/theme=places/type=place/`, Parquet.
- **Лицензия.** CDLA-Permissive-2.0 (условия Overture); внутри набора записи Meta, Foursquare (Apache-2.0), AllThePlaces (CC0-1.0), Microsoft — все допускают печать с подписью. Подпись: «Overture Maps Places <выпуск>».
- **Свежесть и доверие.** Класс C: координаты приблизительные, часть заведений закрыта. Вместимости нет — ее дает реестр через `reconcile`.
- **Кеш.** Тот же каталог, `places-place.parquet`.

## OSM напрямую: Overpass и Geofabrik

- **Что дает.** Те же слои, что Overture, из первоисточника. Море строится из береговой линии `natural=coastline` (суша слева, вода справа). Нужен на Mac с открытой сетью, когда выпуск Overture устарел или нужны теги, которых в Overture нет.
- **Доступ.** Overpass API `https://overpass-api.de/api/interpreter` (адрес в `rules/fetch.yaml`), запрос по охвату строит `cm_carto/fetch/osm.py`; либо `.osm.pbf` Geofabrik (`https://download.geofabrik.de/russia/southern-fed-district-latest.osm.pbf` — регион уточнить по проекту), переводится в `.osm` командой `osmium extract -b <охват> регион.osm.pbf -o data.osm` и подается в `--file data.osm --date ГГГГ-ММ-ДД`.
- **Лицензия.** ODbL 1.0, подпись «© участники OpenStreetMap», как выше.
- **Свежесть.** Overpass — на момент запроса, дата пишется в `SOURCE.yaml`; Geofabrik — ежедневный снимок региона.
- **Кеш.** `input/<проект>/cache/osm/data.osm` и `SOURCE.yaml`; готовый кеш сеть не трогает.
- **Ограничения.** Из облака хосты закрыты (403): путь проверен только на синтетическом `.osm` (тест `tests/test_fetch_osm.py`); на живых данных не проверен. Чтение `.osm` идет через osmnx целиком в память — для региона целиком брать выгрузку по охвату проекта.

## bus.gov.ru: учреждения

- **Что дает.** Школы, детские сады, поликлиники и больницы с наименованием, адресом, вместимостью → сверка с `poi_education`, `poi_health` (команда `reconcile`). Координат, как правило, нет: запись без координат сводится с объектом OSM по названию (единственное совпадение) и не добавляется в геопакет, если пары нет (список — в отчете сверки).
- **Доступ.** `https://bus.gov.ru` (раздел открытых данных, выгрузки таблиц). Файл CSV с разделителем `;` кладется в кеш командой `cm-carto fetch <project.yaml> bus_gov --file F.csv --date ГГГГ-ММ-ДД`. Названия столбцов — в `rules/registries.yaml` (`bus_gov.columns`); они не сверены с живой выгрузкой: хост закрыт, первая сверка на Mac, правка — в правилах, не в коде.
- **Лицензия.** Открытые данные сайта; точные условия повторного использования не проверены (хост закрыт). Записано как «открытые данные bus.gov.ru, условия сайта»; уточнить до печати.
- **Свежесть.** Сведения учреждения обновляются по мере подачи; дата выгрузки — из `--date`.
- **Класс.** A (подает само учреждение).
- **Кеш.** `input/<проект>/cache/registries/bus_gov/data.csv`, `SOURCE.yaml`.
- **Ограничения.** Закрыт из облака; разборщик проверен только на синтетическом фрагменте. Публичный REST сайта (`/public-rest/api/...`) не документирован как открытый интерфейс — не используется.

## Реестр ОКН (Минкультуры России, opendata.mkrf.ru)

- **Что дает.** Слой `heritage`: точки объектов культурного наследия с номером в реестре, видом и категорией значения (`federal`, `regional`, `local`, `identified`). Территории и зоны охраны в этом наборе нет — они приходят в `zouit` через `ingest` из выписок.
- **Доступ.** Набор «Единый государственный реестр объектов культурного наследия» — `https://opendata.mkrf.ru/opendata/7705851331-egrkn/`, архив CSV. Столбцы (по чтению набора сторонним кодом): «Объект», «Регион», «Вид объекта», «Категория историко-культурного значения», «На карте» (GeoJSON-точка). Столбец номера («Номер в реестре») не подтвержден: при расхождении имен правится `rules/registries.yaml`.
- **Лицензия.** Условия портала; точная лицензия набора не проверена (хост закрыт). Записано как «открытые данные портала opendata.mkrf.ru, условия портала»; уточнить до печати.
- **Свежесть.** Реестр обновляется Минкультуры; дата выгрузки — из `--date`.
- **Класс.** A; геометрия — точка из реестра, статус `reference`.
- **Кеш.** `input/<проект>/cache/registries/okn/`.
- **Ограничения.** Закрыт из облака; зеркала на GitHub найти не удалось (поиск по коду и репозиториям); проверено только на синтетическом фрагменте. Записи без координат в слой не попадают.

## Реестр классифицированных средств размещения

- **Что дает.** Гостиницы с названием, категорией, адресом, числом мест → сверка с `poi_hotels` (`reconcile`); вместимость идет в `capacity`.
- **Доступ.** Федеральный перечень классифицированных средств размещения (Росаккредитация); выгрузка CSV вручную, `--file`, `--date`. Адрес выгрузки и названия столбцов (`rules/registries.yaml`, `hotels`) не сверены с живым набором.
- **Лицензия.** Открытые данные реестра, условия портала; не проверена.
- **Класс.** A. **Кеш.** `cache/registries/hotels/`. **Ограничения.** Закрыт из облака; только синтетический фрагмент.

## ДТП ГИБДД

- **Что дает.** Слой `accidents`: дата, тяжесть (`fatal`, `injury`, `damage`) и место. Участников, транспортных средств и описаний не берем: карточки ДТП содержат персональные данные, контракт их не допускает.
- **Доступ.** `stat.gibdd.ru` (карточки ДТП) и зеркало `dtp-stat.ru` («Карта ДТП»); выгрузка CSV, `--file`, `--date`. Столбцы — `rules/registries.yaml`, `dtp`; не сверены с живой выгрузкой.
- **Лицензия.** Открытые данные ГИБДД, условия портала; не проверена. Для dtp-stat.ru условия проекта проверить отдельно.
- **Класс.** A. **Кеш.** `cache/registries/dtp/`. **Ограничения.** Закрыт из облака; тяжесть выводится из чисел погибших и раненых; только синтетический фрагмент.

## Росстат

- **Что дает.** Показатели муниципальных образований (население и др.) как таблица `geo/rosstat.csv` (показатель, единица, год, значение, ОКТМО) для реестра фактов базы. Площади и числа в карту идут из реестра базы, а не из измерений.
- **Доступ.** `rosstat.gks.ru`, база показателей муниципальных образований; выгрузка в длинную таблицу CSV, `--file`, `--date`; столбцы — `rules/registries.yaml`, `rosstat`.
- **Лицензия.** Свободное использование с указанием источника; формулировка условий сайта не проверена.
- **Класс.** A. **Кеш.** `cache/registries/rosstat/`. **Ограничения.** Закрыт из облака; формат выгрузки предположен, не проверен.

## НСПД (Национальная система пространственных данных)

Не подключается. Причины: публичного документированного программного интерфейса для массовой выгрузки нет; хост закрыт из облака; автоматизированное снятие данных с портала правилами использования, насколько известно, не разрешено без соглашения (текст правил проверить Роману). Сведения ЕГРН проект получает выписками и КПТ через `ingest`; это же дает статус `cadastral`, которого `fetch` дать не может.

## Яндекс, 2ГИС, Google

Только сверка и счет (например, проверить, что число школ в районе не отличается от реестра в разы). Подложки, данные и геометрия этих сервисов в карты для печати и в геопакет не попадают; кеша их ответов в проекте нет; модуля `fetch` для них нет.
